# 存储贡献生命周期

模块保存用户同意、贡献条件、请求状态、存储端观测、审计和 outbox。凭据授权与根目录验证由存储接入负责，贡献模块不持有密码、会话或密钥。奖励由可选账务模块负责，本模块不授予积分。

## 绑定与同意

创建请求引用已验证、已暂停且没有占用、预留或副本的用户实例。实例所有权通过 issuer 与 subject 的散列绑定。用户必须明确接受当前版本及摘要的条款。平台实例、其他用户实例和未开放 adapter 都不能贡献。

容量、个人保留空间、期限、退出目标时间和单人数量由配置给出。总登记上限为 100，与当前存储实例预算一致。已关闭记录继续占用登记额度，防止不受限制地重复授权和创建记录。更大规模及历史归档需要后续容量设计。

每个实例只建立一个永久贡献记录。24 小时内保留幂等响应，相同键与不同请求冲突；响应过期后，唯一绑定仍阻止重复贡献。所有请求及重放都检查当前身份和授权。

用户选项接口只返回本人已授权、暂停且尚未绑定的空实例。列表不触发供应商登录或探测，不暴露凭据和根目录。尚未应用的贡献请求也会排除对应选项。

## 状态与恢复

创建、暂停、恢复、条件更新、续期、退出、撤权和重试返回 202。响应的 desired_state 表示用户请求，state 表示处理状态，applied_revision 表示存储端已确认的修订。pending 不表示暂停或退出已经生效。

暂停停止接收新文件，保留既有副本。退出将实例设为 draining，由存储维护流程迁移资料，并记录 exit_initial_replicas 与 exit_initial_used_bytes 基线供展示迁移进度；副本记录、占用和预留量全部归零才确认 exited。退出不能取消，目标时间是运维目标，超过后读取视图与后台刷新均显示 exit_overdue。

创建与 configure 支持最多 32 个字符且去除控制字符的 display_label 备注，仅在本人详情与列表视图返回，管理端、公开汇总及事件一律剥离。

撤权立即请求停止使用实例。确认撤权后仍有副本或占用时显示 cleanup_unconfirmed 并继续只读观测账本，归零后结束任务并从公开统计排除；未清理完成前不能显示退出完成。重新授权由凭据接入完成；贡献请求通过 retry 重试原目标，不自行延长供应商授权。

用户同意期限由存储核心在写入、任务执行和放置时检查。贡献后台未运行也不会继续新写入。到期扫描仅加锁已到期记录并分批清理过期幂等缓存；退出时若授权已过期，后台持续读取存储账本。确认旧控制已停写且副本、占用和预留均为零后结束退出。applied_revision 保留存储端实际确认的修订。

观测最大有效期至少为刷新间隔的两倍；读取视图按优先级分别显示同意到期、观测超龄、授权失效与配额未知，公开统计只汇总新鲜观测的占用与可用量。

后台通过租约领取任务，并为领取、远端同步和结果落库使用独立子超时。存储超时与乐观锁竞态执行有上限退避重试；调用方取消时保留租约供恢复。纯心跳只更新观测时间。已停止的旧退出任务在升级时恢复；Sweep 单次最多清理 1000 条过期回执，返回的游标可继续清理。

可选 Worker 提供有界并发、空闲退避、Sweep 游标续扫与 15 秒优雅停机预算。

策略配置提前续期预警秒数（默认 7 天）。进入预警窗口时视图返回 consent_expiring_soon 或 authorization_expiring_soon；扫描与同步按周期幂等写入带 .v1 版本号的领域事件并透传合法 traceparent。

## 数据和接口

独立 contribution schema 与运行身份拥有本模块数据。业务变化、审计和 outbox 在同一事务保存并通过 contribution_outbox 通道发送通知。运行身份不能修改或清空审计、创建对象，也不能访问除 contribution 外的任何业务或公共 schema。迁移身份单独运行 schema.sql。

outbox 使用单调序号按主题保序投递，读取前排除退避、人工处理或指定阻塞主题，避免队头阻塞。失败从 5 秒指数退避至 1 小时，满 24 小时转人工处理；确认不存在的事件返回未找到，重复确认保持原完成时间。

OpenAPI 定义用户接口、公开策略及公开汇总，Go 与 TypeScript SDK 由命令生成。列表最多 100 条，后台扫描和事件读取有单次上限。公开统计不包含账号、所有者、凭据或实例位置，统计区分申报量与仍有效的观测容量。

公开汇总采用单实例进程内单飞合并与短有效期缓存（数据来源为贡献表扫描，默认 TTL 5 秒，写操作、到期扫描与任务变更主动失效）。相邻有效且授权合规的活跃观测窗口累积只增不减的核验活跃秒数与容量时长（字节·小时），仅在本人视图返回。

身份验证器必须提供已验证请求人，Authorizer 必须检查当前动作权限。服务身份只调用贡献维护及存储贡献接口。业务 API 不接收调用方指定的 owner。真实入口、授权配置与生产部署保持关闭，独立测试不访问学校账号。

管理员通过独立的读取和重试权限查看脱敏任务，可按 state、reason、adapter 筛选，并查看 job_state、attempts、max_attempts 与 available_at 重试进度；未知或重复查询参数返回 400。

重试只恢复原请求，保留容量、期限、同意和退出决定。运维指标快照接口汇总状态、原因、调度计数与 outbox 未投递积压。普通用户权限不能读取全局任务，后台身份不能获得这些管理权限。

浏览器 SDK 校验响应字段、整数范围和时间，使用同源认证及禁止缓存。错误响应保持顶层 code 兼容，并提供封闭枚举 detail_code 与容量冲突下的 min_required_bytes，供多语言界面精确提示。写请求结果未知时调用方必须保留原请求与幂等键。

升级时按事件载荷中的修订号恢复旧记录的主题内顺序，保留投递确认状态。

升级时将旧版本已停止、仍有残留占用的撤权任务恢复为待观测。已清零的撤权记录保持终止。

运维列表在事务外检查准入，读取快照后释放连接，再核验各对象的可见性。宿主可实现 OperationReadAuthorizer，在一次批量检查中返回整页决定。旧授权器保留列表准入和逐对象校验。分页只计可见记录，游标取本页最后一个可见对象。

下调登记额度只限制新增贡献。选项排除本人的全部历史绑定和未开放适配器后再分页。公开统计读取登记表中的全部贡献，使用仓库固定上限 100 条。

写操作接受 1 到 128 个可打印 ASCII 字符组成的幂等键，按时间点比较期限。创建前先验证当前权限和本地回执。同键不同请求返回 409，无权访问和缺失的存储实例统一返回 404。浏览器区分未找到、冲突和取消，并在发送前检查资源路径。

## 验收

| 场景 | 预期结果 |
| --- | --- |
| CONTRIB-01 | 同意、所有权、并发重复请求和撤权后的重放均受约束 |
| CONTRIB-02 | 暂停、恢复、续期与退出迁移具有可核验结果 |
| CONTRIB-03 | 丢失响应能恢复，迟到激活不能覆盖已生效的暂停 |
| CONTRIB-04 | 到期停止可用统计，退出与响应清理保留唯一绑定 |
| CONTRIB-05 | 失败重试有上限，撤权、数据库隔离与事件交付可核验 |
| CONTRIB-06 | 生成 SDK 验证真实 HTTP 入口、匿名权限及敏感字段边界 |
| CONTRIB-07 | 本人选项不包含已绑定实例，管理重试保留同意并检查实时权限 |
| CONTRIB-12 | 实例备注仅本人可见不向管理端或事件泄露，退出保留初始副本与占用基线 |
| CONTRIB-10 | 冲突与输入拒绝返回精确 detail_code 及最小可设容量字节数 |
| CONTRIB-13 | 后台调度器、额度冲突、退出超期、学校范围管理隔离与运行身份负向校验均受约束 |
| CONTRIB-14 | 公开统计单飞短缓存支持时钟过期与变更主动失效，核验容量时长仅在有效活跃窗口单调累积 |
| CONTRIB-09 | 即将到期预警按周期幂等触发，状态变迁输出 .v1 版本化事件并透传追踪头 |
| CONTRIB-11 | 运维列表支持状态/原因/适配器筛选与任务重试进度，指标快照受运维权限保护 |

## 保留与交付

幂等响应保留 24 小时，由有界维护扫描清理。贡献记录、同意证据、审计及 outbox 保存在本模块私有数据库；当前数量受登记上限约束，正式部署前须按使用规模配置归档、事件交付与告警。尚未实现自动积分、贡献榜或真实供应商授权入口。
