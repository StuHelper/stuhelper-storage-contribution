# 存储贡献生命周期

模块保存用户同意、贡献条件、请求状态、存储端观测、审计和 outbox。凭据授权与根目录验证由存储接入负责，贡献模块不持有密码、会话或密钥。奖励由可选账务模块负责，本模块不授予积分。

## 绑定与同意

创建请求引用已验证、已暂停且没有占用、预留或副本的用户实例。实例所有权通过 issuer 与 subject 的散列绑定。用户必须明确接受当前版本及摘要的条款。平台实例、其他用户实例和未开放 adapter 都不能贡献。

容量、个人保留空间、期限、退出目标时间和单人数量由配置给出。总登记上限为 100，与当前存储实例预算一致。已关闭记录继续占用登记额度，防止不受限制地重复授权和创建记录。更大规模及历史归档需要后续容量设计。

每个实例只建立一个永久贡献记录。24 小时内保留幂等响应，相同键与不同请求冲突；响应过期后，唯一绑定仍阻止重复贡献。所有请求及重放都检查当前身份和授权。

## 状态与恢复

创建、暂停、恢复、条件更新、续期、退出、撤权和重试返回 202。响应的 desired_state 表示用户请求，state 表示处理状态，applied_revision 表示存储端已确认的修订。pending 不表示暂停或退出已经生效。

暂停停止接收新文件，保留既有副本。退出将实例设为 draining，由存储维护流程迁移资料。副本记录、占用和预留量全部归零才确认 exited。退出不能取消，目标时间是运维目标，超过后显示 exit_overdue。

撤权立即请求停止使用实例。确认撤权后仍有副本时显示 cleanup_unconfirmed，不能显示退出完成。重新授权由凭据接入完成；贡献请求通过 retry 重试原目标，不自行延长供应商授权。

用户同意期限由存储核心在写入、任务执行和放置时检查。贡献后台未运行也不会继续新写入。到期扫描记录退出请求。存储不可用、授权失效及配额未知分别显示原因，有效容量不使用过期观测。

后台通过租约领取任务，在外部操作前提交事务。贡献修订与任务代次分别阻止迟到请求和迟到结果覆盖新状态。失败采用有上限的退避；超过配置次数后保留 blocked 状态，等待明确重试。取消时保留租约供恢复，不另起无期限任务。

## 数据和接口

独立 contribution schema 与运行身份拥有本模块数据。业务变化、审计和 outbox 在同一事务保存。运行身份不能修改审计、创建表或访问 storage、media、billing schema。迁移身份单独运行 schema.sql。

OpenAPI 定义用户接口、公开策略及公开汇总，Go 与 TypeScript SDK 由命令生成。列表最多 100 条，后台扫描和事件读取有单次上限。公开统计不包含账号、所有者、凭据或实例位置，统计区分申报量与仍有效的观测容量。

身份验证器必须提供已验证请求人，Authorizer 必须检查当前动作权限。服务身份只调用贡献维护及存储贡献接口。业务 API 不接收调用方指定的 owner。真实入口、授权配置与生产部署保持关闭，独立测试不访问学校账号。

## 验收

| 场景 | 预期结果 |
| --- | --- |
| CONTRIB-01 | 同意、所有权、并发重复请求和撤权后的重放均受约束 |
| CONTRIB-02 | 暂停、恢复、续期与退出迁移具有可核验结果 |
| CONTRIB-03 | 丢失响应能恢复，迟到激活不能覆盖已生效的暂停 |
| CONTRIB-04 | 到期停止可用统计，退出与响应清理保留唯一绑定 |
| CONTRIB-05 | 失败重试有上限，撤权、数据库隔离与事件交付可核验 |
| CONTRIB-06 | 生成 SDK 验证真实 HTTP 入口、匿名权限及敏感字段边界 |

## 保留与交付

幂等响应保留 24 小时，由有界维护扫描清理。贡献记录、同意证据、审计及 outbox 保存在本模块私有数据库；当前数量受登记上限约束，正式部署前须按使用规模配置归档、事件交付与告警。尚未实现自动积分、贡献榜或真实供应商授权入口。
