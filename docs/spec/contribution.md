# 存储贡献生命周期

模块保存用户同意、贡献条件、请求与任务、存储账本观测、审计和 outbox。凭据验证、云盘容量采集、根目录和副本账本由 storage 管理。

`module.json` 声明 storage 为必需依赖，实例准入、额度校验和状态同步使用其公开接口。billing 是可选依赖，贡献操作和统计可独立运行。自动积分、贡献榜及贡献到账务的接入已延期。

## 绑定与同意

创建请求引用已验证、暂停且没有占用、预占或副本的本人实例。实例所有权通过 issuer 与 subject 的散列绑定。用户须接受当前贡献条款的版本和摘要，且适配器已开放。凭据托管和存储贡献分别取得同意。

运维可在记录拥有者的独立同意后登记现有已核验实例。审批输入包括实例修订和同意凭证。贡献任务调用存储接口核对准入、账号和额度，保留凭据、目录、占用与副本，成功后纳入本人贡献和公开统计。

已获准登记的现有实例在批准期限内保留原额度。普通新贡献及跨过批准期限的续期遵循通用申报上限。

容量、个人保留空间、期限、退出目标和单人名额由配置和实例条件决定。贡献总名额的配置上限为 100，已确认退出的记录释放名额。下调名额只约束后续登记。同一用户在配置窗口内的激活次数另有限制。

每个实例绑定一条永久贡献记录。24 小时内保留幂等响应，同键异参返回冲突。响应过期后，唯一绑定仍阻止重复创建。所有写操作及重放均检查当前身份和授权。

已确认 `exited` 且无残留占用的实例可经 `reopen` 重新同意当前条款。请求沿用贡献 ID 并递增修订。存储锁定实例，核对原绑定、当前授权、已用字节、预占及副本数后恢复写入。

`GET /api/v1/storage-contributions/options` 在分页前排除本人所有历史绑定和未开放的适配器，只列出仍获授权、已暂停且空闲的候选实例。候选查询只读取账本和托管绑定，不触发供应商登录。

本人贡献记录、候选项及有权管理的贡献记录可返回 `account_hint`，账号事实缺失时省略。BHpan 登录名至少五个字符时保留前两位与后两位，中间逐位替换为 `*`。较短时仅保留末位，前面至少加一个 `*`。公开统计、审计和事件省略该字段。

## 云盘容量与申报上限

接入成功后重新读取本人的候选项。`max_contributable_bytes` 是个人保留为零时的上限，等于剩余字节扣除实例安全余量，最低为零。填写个人保留后再从上限扣除相应字节，结果最低为零且须符合策略。BHpan 托管登记默认安全余量为 0 B，已有实例沿用自身配置。

创建、重开，以及配置或续期时提高申报额度或减少个人保留空间，均要求当前供应商读数。超限返回 HTTP 400，`detail_code` 为 `limit_exceeds_provider_capacity`。当前读数不可用时返回 HTTP 409，`detail_code` 为 `provider_capacity_unavailable`。

存储在应用条件的事务内复核额度。复核发现申报越过当前上限时，任务进入阻塞，原因是 `limit_exceeds_provider_capacity`。读数暂不可用时，贡献保持阻塞，任务按观测间隔再试。

本人容量视图使用 `provider_capacity.status`。当前样本有效时为 `available`，无读数时为 `not_read`，最近刷新失败时为 `read_failed`，成功样本到期且没有刷新失败记录时为 `expired`。贡献原因字段分别以 `capacity_unknown`、`capacity_read_failed`、`capacity_expired` 对应后三种状态。

`provider_capacity` 仅随本人候选项、列表和详情返回。`total_bytes`、`used_bytes` 和 `remaining_bytes` 是整个云盘的字节数。剩余量为总量减已用量，最低为零。后三种状态下，三个空间字段与候选项的 `max_contributable_bytes` 均为 `null`。

`provider_capacity.observed_at` 和 `observation.observed_at` 都取最后一次已记录的成功容量采样时间，缺少记录时为 `null`。平台账本的已用、预占和可用量分别读取 `observation` 中的对应字段。公开统计、运维接口、审计和事件省略云盘原始容量。

存储刷新恢复后，本人列表与详情会在同一已应用修订下使用当前存储账本重新计算有效容量。

## 状态与恢复

本人创建及生命周期命令返回 HTTP 202。`desired_state` 表示请求目标，`state` 表示处理状态，`applied_revision` 表示存储端已确认的修订。客户端通过本人查询确认暂停或退出已生效。

暂停停止接收新文件，保留既有副本。退出令实例进入 `draining`，由存储迁移副本。退出初始副本数和占用字节通过 `exit_initial_replicas` 与 `exit_initial_used_bytes` 提供。

副本、占用和预占量全部归零后确认 `exited`。退出提交后持续推进，超过目标时间时视图与后台刷新显示 `exit_overdue`。

创建和 `configure` 支持本人备注 `display_label`。服务端先检查原始值不超过 256 个 UTF-8 字节，再移除控制字符并去掉首尾空白。最终允许最多 32 个 Unicode 字符和 128 字节，备注只随本人记录返回。

`configure` 传空字符串清除备注，省略备注字段则保留原值。仅改备注时可以省略 `conditions`，额度、个人保留空间和到期时间保持原值。请求仍需当前贡献修订和幂等键。

撤权立即请求停止使用实例。确认撤权后仍有副本或占用时显示 cleanup_unconfirmed 并继续只读观测账本，归零后结束任务并从公开统计排除；未清理完成前不能显示退出完成。重新授权由凭据接入完成；贡献请求通过 retry 重试原目标，不自行延长供应商授权。

存储核心在写入、任务执行和放置时校验同意期限，到期独立停止新写入。贡献后台仅锁定已到期的记录。退出时若授权已过期，后台继续读取账本，确认停写且副本、占用和预占均为零后完成退出。`applied_revision` 保留存储端实际确认的修订。

账本观测的最大有效期至少为刷新间隔的两倍。视图按优先级报告同意到期、账本观测超龄、供应商授权失效和容量读取状态。后台核对账本的时间单独维护，用于计算观测新鲜度。

后台通过租约领取任务，领取、同步和落库分别使用独立子超时。存储超时与乐观锁冲突按策略退避，调用方取消后通过租约到期恢复。只更新账本观测时间的心跳无需新审计和事件。Sweep 单次最多清理 1000 条过期回执，返回游标供续扫。

可选 Worker 提供有界并发、空闲退避、Sweep 游标续扫与 15 秒优雅停机预算。

策略配置提前续期预警秒数（默认 7 天）。进入预警窗口时视图返回 consent_expiring_soon 或 authorization_expiring_soon；扫描与同步按周期幂等写入带 .v1 版本号的领域事件并透传合法 traceparent。

## 数据和接口

独立 contribution schema 与运行身份拥有本模块数据。业务变化、审计和 outbox 在同一事务保存并通过 contribution_outbox 通道发送通知。运行身份对 audit_retention 只读，不能修改或清空审计、创建对象，也不能访问除 contribution 外的任何业务或公共 schema。迁移身份单独运行 schema.sql。

outbox 使用单调序号按主题保序投递，读取前排除退避、人工处理或指定阻塞主题，避免队头阻塞。失败从 5 秒指数退避至 1 小时，满 24 小时转人工处理；确认不存在的事件返回未找到，重复确认保持原完成时间。

越权拒绝与管理端查看记录脱敏审计，管理员重试使用独立的 contribution.operation_retried.v1 动作。audit 表提供结构化列、时间倒序索引与受独立读取权限保护的只读快照分页查询。

`contracts/contribution.openapi.json` 定义用户、公开和专用运维接口，`make generate` 生成 SDK。列表最多 100 条，后台扫描和事件读取设置单次上限。

`GET /api/v1/storage-contributions/statistics` 汇总登记贡献，区分用户申报量和账本中的占用、预占和当前可用量。占用、预占和可用量来自新鲜观测，已退出与确认清理完毕的撤权贡献从统计移除。公开结果只含聚合数据。

统计按每页 100 条扫描贡献表，并复用进程内同一次计算。缓存默认 5 秒，写操作、到期扫描与任务变更主动失效。相邻有效且授权合规的活跃观测窗口累积核验活跃秒数及容量时长，容量时长单位为字节·小时。这些核验值仅在本人视图返回。

宿主验证请求人，Authorizer 检查当前动作权限。本人 API 从验证后的身份确定所有者。服务身份执行贡献维护和已核验实例登记，并调用相应的存储接口。供应商凭据仅由存储接入处理。

管理员通过独立的读取和重试权限查看脱敏任务，可按 state、reason、adapter 筛选，并查看 job_state、attempts、max_attempts 与 available_at 重试进度；未知或重复查询参数返回 400。

重试只恢复原请求，保留容量、期限、同意和退出决定。运维指标快照接口汇总状态、原因、调度计数与 outbox 未投递积压。普通用户权限不能读取全局任务，后台身份不能获得这些管理权限。

浏览器 SDK 校验响应字段、整数范围和时间，使用同源认证及禁止缓存。错误响应保持顶层 code 兼容，并提供封闭枚举 detail_code 与容量冲突下的 min_required_bytes，供多语言界面精确提示。写请求结果未知时调用方必须保留原请求与幂等键。

升级时按事件载荷中的修订号恢复旧记录的主题内顺序，保留投递确认状态。

升级时将旧版本已停止、仍有残留占用的撤权任务恢复为待观测。已清零的撤权记录保持终止。

运维列表在事务外检查准入，读取快照后释放连接，再核验各对象的可见性。宿主可实现 OperationReadAuthorizer，在一次批量检查中返回整页决定。旧授权器保留列表准入和逐对象校验。分页只计可见记录，游标取本页最后一个可见对象。

写操作接受 1 到 128 个可打印 ASCII 字符组成的幂等键，按时间点比较期限。创建前先验证当前权限和本地回执。同键不同请求返回 409，无权访问和缺失的存储实例统一返回 404。浏览器区分未找到、冲突和取消，并在发送前检查资源路径。

`module.json` 的 `scenario_tests` 登记各场景的测试文件和函数。单仓集成测试执行独立 PostgreSQL 迁移，注入身份和供应商夹具。实际账号验收随宿主装配记录。

## 保留与审计分页

有界维护扫描清理到期的幂等响应。贡献记录、同意证据、审计和 outbox 由本模块私有数据库保存，宿主负责归档、事件交付和告警。

审计分页的快照令牌上限为 256 字节。较长的 PostgreSQL 活动事务列表使用事务号差值压缩，继续分页时恢复原可见范围。历史审计升级后按原信封时间、动作与目标查询，所属学校优先取已记录学校，其次取贡献所有者的学校。
